Reflection

I made some adjustments to the CSS to solve the problem of the images in the previous image gallery protruding out of the grid. By adding "overflow: hidden" to the .gallery-item, its function is to directly cut off the content that exceeds the grid range, so that the images will not stretch beyond the layout. Combined with the "object-fit: cover" in the .gallery-item img, the images will fill the grid while maintaining their original proportions, and the excess part will be cropped instead of expanding the container. When these two attributes are combined, the images will no longer protrude.

Reflection

In the .lightbox-container img, the property object-fit: contain is used. This will make the image resize to exactly fit the size of the container without any cropping or distortion. At the same time, the max-height: 85vh is set to limit the image to occupy no more than 85% of the screen height, preventing overly large images from exceeding the screen boundaries.

Opening windows code

In the image gallery, I also added content in video and PDF formats. The videos were embedded using the 'video' tag, and the controls attribute was used to allow users to play and pause them directly on the page. In CSS, the video is set to have the same width and height as the images, with the object-fit property set to cover, so that it maintains the same appearance as the other image grids. For the PDF, an tag is used to create a clickable white card. When clicked, the file opens in a new tab. The display: flex property is used to centre the content, visually aligning it with the other grids, but the click behaviour is different.
